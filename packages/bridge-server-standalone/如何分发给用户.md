# 如何分发 Bridge Server 给用户

## 快速开始

你创建了一个独立的 Bridge Server 包，现在有多种方式分发给用户。

## 📦 分发方式对比

| 方式 | 难度 | 用户体验 | 适用场景 |
|------|------|----------|----------|
| **npm 发布** | ⭐⭐ | ⭐⭐⭐⭐⭐ | 正式发布 |
| **tarball 分发** | ⭐ | ⭐⭐⭐ | 内部测试、快速分享 |
| **npx 使用** | ⭐⭐ | ⭐⭐⭐⭐ | 临时使用 |
| **源码分发** | ⭐⭐⭐ | ⭐⭐ | 开发者 |

## 🚀 方式 1: npm 发布（推荐）

### 第一步：准备发布

```bash
cd /Users/peter/Documents/automation-test/midscene/packages/bridge-server-standalone

# 1. 确保依赖包已发布
# 如果 @midscene/core 和 @midscene/shared 还未发布，需要先发布它们

# 2. 修改 package.json 的依赖
# 将 "workspace:*" 改为实际版本号，例如 "^0.30.2"

# 3. 安装依赖
pnpm install

# 4. 构建
pnpm build

# 5. 测试（可选）
npm pack
npm install -g ./midscene-bridge-server-standalone-*.tgz
midscene-bridge --help
npm uninstall -g @midscene/bridge-server-standalone
```

### 第二步：发布到 npm

```bash
# 登录 npm（如果还没登录）
npm login

# 发布
npm publish --access public
```

### 用户如何使用

用户只需要：

```bash
# 全局安装
npm install -g @midscene/bridge-server-standalone

# 运行
midscene-bridge

# 或者用 npx（无需安装）
npx @midscene/bridge-server-standalone
```

## 📦 方式 2: tarball 分发（最简单）

### 创建 tarball

使用提供的脚本：

```bash
cd /Users/peter/Documents/automation-test/midscene/packages/bridge-server-standalone

# 运行打包脚本
./scripts/build-and-pack.sh
```

这会生成一个文件，例如：`midscene-bridge-server-standalone-0.1.0.tgz`

### 分发给用户

1. **直接发送文件**
   - 通过邮件、云盘等方式发送 `.tgz` 文件

2. **放到服务器**
   - 上传到你的服务器或 CDN
   - 给用户一个下载链接

### 用户如何使用

```bash
# 从本地文件安装
npm install -g /path/to/midscene-bridge-server-standalone-0.1.0.tgz

# 从 URL 安装
npm install -g https://your-server.com/path/to/midscene-bridge-server-standalone-0.1.0.tgz

# 运行
midscene-bridge
```

## 🔧 常见问题处理

### 问题 1: 依赖包未发布

如果 `@midscene/core` 或 `@midscene/shared` 还没发布到 npm：

**临时方案**：使用 tarball 分发，用户安装时会自动从本地 monorepo 解析依赖。

**长期方案**：先发布依赖包：

```bash
# 发布 core
cd packages/core
npm publish --access public

# 发布 shared
cd ../shared
npm publish --access public

# 然后发布 bridge-server-standalone
cd ../bridge-server-standalone
npm publish --access public
```

### 问题 2: 用户没有 Node.js

如果用户机器没有 Node.js，可以：

1. **让用户安装 Node.js**（推荐）
   - 访问 https://nodejs.org/
   - 下载并安装 LTS 版本

2. **打包成独立可执行文件**（高级）
   ```bash
   npm install -g pkg
   cd packages/bridge-server-standalone
   pnpm build
   
   # 为不同平台打包
   pkg dist/cli.js --targets node18-macos-x64 --output ../../midscene-bridge-macos
   pkg dist/cli.js --targets node18-linux-x64 --output ../../midscene-bridge-linux
   pkg dist/cli.js --targets node18-win-x64 --output ../../midscene-bridge-win.exe
   ```

### 问题 3: 端口冲突

告诉用户可以使用不同端口：

```bash
midscene-bridge --port 3767
```

## 📊 推荐的分发流程

### 内部测试阶段

1. 使用 `./scripts/build-and-pack.sh` 创建 tarball
2. 发送给内部测试人员
3. 收集反馈

### 正式发布阶段

1. 修复测试中发现的问题
2. 更新版本号：`npm version patch`
3. 发布到 npm：`npm publish --access public`
4. 通知用户：`npm install -g @midscene/bridge-server-standalone`
